# Array_Cardio_Day_2

***I used Javascript to practice array methods. The ones I explored were some(), every(), find(), and findIndex(). I used some() to find out if there were some people in the dataset that were 19 years of age or older. I used every() to make sure every single person was 19 years of age or older. I used find() to find the comment with a specific id number within the dataset. Lastly, I implemented findIndex() to find the index of the comment with the specific id to delete it from the dataset.***
